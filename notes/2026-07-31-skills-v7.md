# Skills v7: referenced context, cross-file flow and precision

## Motivation

The version 6 skills agent had three measurable recall gaps: explicit Python
and JavaScript cross-file credential exfiltration, and prompt injection hidden
in an HTML file that `SKILL.md` directed the agent to load. It also treated
unreferenced fixtures as live context, joined unrelated secret and network
operations, and raised governance findings on defensive approvals and
hardening guidance.

## Changes

- Context analysis now starts from skill entrypoints and follows only files
  explicitly loaded by active instructions. Unreferenced test fixtures do not
  enter the context plane.
- Active scripts include the local Python/JavaScript import closure of code the
  skill actually directs the agent to run.
- Python and JavaScript cross-file secret flows require an explicit coordinator
  edge. Same-file JavaScript sources and sinks are correlated within a function.
- Shared-file flows require two distinct modules and a concrete common path;
  MIME strings such as `application/json` are not treated as file paths.
- Runtime phase capabilities are attributed only to active scripts.
- Defensive approvals, mitigations, least-privilege warnings and governance
  reports are suppressed without weakening autonomous-tool findings.

benign twins alongside a malicious shared-file control.

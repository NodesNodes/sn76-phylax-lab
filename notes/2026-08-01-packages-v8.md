# Packages v8: indirect import and credential-flow recall

## Motivation

Packages v7 scored `0.434634` (rank 26/50) and was excluded after its previous
round. Its precision hardening left five measurable false-negative shapes:
dynamic Python/JavaScript imports, named tokens sent as payload data, and
optional dependencies participating in dependency-confusion resolution.

## Changes

- JavaScript dynamic `import()` and Python `importlib.import_module` /
  `__import__` now participate in package import and lifecycle reachability.
- Named environment tokens become credential theft only when data flow reaches
  a request body, query payload, file upload or Axios positional payload.
- Intended API tokens used only in Authorization headers remain benign.
- Install/import-time transformed token flow remains detected, while deferred
  runtime SDK methods are not treated as automatic exfiltration.
- `optionalDependencies` and `peerDependencies` join dependency inventory and
  confusion analysis; artifact-provided private registry pins remain honored.
- The package LLM dossier now prioritizes dynamic imports, build backends,
  lifecycle hooks, optional dependencies and credential-flow terms.

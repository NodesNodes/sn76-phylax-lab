# Skills v8: indirect-flow recall without real-corpus precision loss

## Motivation

The production Skills v7 score was `0.103785` (rank 51/58). Because the
detonation score weights MCC at 70%, that result implied a severe verdict
classification gap despite perfect local suites. The v7 precision controls had
become too restrictive around active context and code reachability.

## Changes

- Local Markdown links from active instructions now activate bundled context
  even when prose omits an explicit `load` or `read` verb.
- `python -m package.module` resolves to bundled Python code.
- Python `importlib.import_module` / `__import__` and JavaScript dynamic
  `import()` participate in the active-code closure.
- Named secret environment variables sent in request bodies, query payloads or
  uploads are treated as credential flow; intended Authorization-header use
  remains benign.
- Higher-priority/authoritative directive replacement is recognized as
  instruction injection, with fenced defensive examples suppressed.
- Import-reached unsafe modules are attributed back to their directly invoked
  entry point, preserving the expected instruction/action finding pair.
- The Skills LLM dossier grew from 14k to 18k characters, ranks indirect-flow
  terms, allows 750 output tokens and uses an 8.5-second request timeout.
